DISTILAB — DESAIN DUA MODE

Buka DistiLab-Desain.figcraft di FigCraft.
Empat halaman: layar terang, sistem desain terang, layar gelap, sistem desain gelap.
Masing-masing mode berisi sembilan layar.

Pilih Beranda lalu Presentasikan. Tombol di kanan atas berpindah antara mode terang dan gelap.

UI ini sudah diterapkan ke sumber aplikasi versi 1.10.0/build 5.
Desain memakai contoh C14; hasil aplikasi tetap dihitung dari input pengguna.

Untuk membangun ulang desain, jalankan dari Kode-desain:
node build-modes.cjs
Atur FIGCRAFT_CLI bila CLI tidak ada di lokasi bawaan.
