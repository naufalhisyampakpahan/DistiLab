## DistiLab 1.2.0 - APK dengan UI redesign terbaru

Ini APK baru dari source lembar kerja, **bukan APK 1.1.0 lama**.

### Perubahan
- Langsung membuka Data kasus tanpa beranda promosi.
- Navigasi Hitung / Studi / Referensi dan alur Data / Hasil.
- Tombol Hitung kolom di bawah layar.
- Ringkasan tahap dan grafik dalam satu alur.
- Rumus serta substitusi dibuka per langkah; audit numerik terpisah.
- Perhitungan ulang kembali ke ringkasan hasil baru.

### Unduh dan perbarui
Pilih **DistiLab-1.2.0.apk** pada Assets, buka di Android 7.0 atau lebih baru, lalu izinkan pemasangan dari sumber tersebut jika diminta. Tidak perlu Expo Go atau komputer.

Package id.distilab.app; versi 1.2.0; versionCode 3. Tanda tangan cocok dengan APK 1.1.0 sehingga dapat dipasang sebagai pembaruan tanpa menghapus aplikasi lama. Tetap ekspor studi penting sebagai cadangan. Jangan hapus aplikasi untuk mengatasi pesan pemasangan sebelum memeriksa penyebabnya.
